# Changelog

## 0.1.0-rc.6

### Create, preview, and deliver pixel animation

- Play local projects with `pixelforge play`: inspect animation timing with playback, pause, and frame stepping.
- Keep Agent edits coordinated with cross-process project locks, atomic file replacement, and optional revision checks.
- Protect project inputs from conflicting preview and export destinations.
- Improve animation guidance around body mechanics, key poses, and follow-through.
- Explore the Nezha spear-attack showcase: 12 editable frames, four layers, transparent animation, and a game sprite sheet.

### 像素动画，从创作到交付

- 本地动画播放器：播放、暂停、逐帧检查动作与节奏。
- Agent 协作编辑：跨进程工程锁、原子保存与可选内容指纹检查。
- 预览与导出路径检查，保护源工程文件。
- 内置动画创作指南强化身体发力、关键姿势与附属物跟随。
- 全新哪吒火尖枪攻击示例：12 帧、四层可编辑工程，附透明动画与游戏图集。
