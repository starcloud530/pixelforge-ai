# 像素画工艺

本 skill 教像素画工艺：走路、机位和运动轨迹。它不是 `pixelforge` 的命令说明书。已安装的 CLI 用 `pixelforge skills read pixel-art-craft` 读本文件，用 `pixelforge skills read pixel-art-craft references/beginner.md`（以及 intermediate / advanced / master）读参考。正文也在仓库的 `.cursor/skills/pixel-art-craft/SKILL.md`。在 PixelForge 工程里落笔时，先遵守 `pixelforge` 的索引色不变量，再按 `pixelforge-draw` 或 `pixelforge-sprite-4dir` 调用 CLI。

*This is a craft skill, not a CLI recipe. A packaged CLI prints this file with `pixelforge skills read pixel-art-craft` and the level references with `pixelforge skills read pixel-art-craft references/<level>.md`. When painting in a PixelForge project, follow the pixelforge invariants first.*

你是完全的初学者。先按下面的顺序做，再按等级打开参考。需要某一课的时候，在这一轮里打开那个 URL，看完再画。不要凭记忆编造课文、帧表或调色数值。

参考按等级分文件，每一级里再按三条柱排列：

1. **走路**：人和其他会走的身体怎么迈步。
2. **视角**：同一对象在侧面、正面、四分之三、俯视、等距、游客视平线、航拍里怎么搭建，以及混用机位时哪里会坏。
3. **运动轨迹**：不同解剖和结构在物理世界里怎么动。双足、四足、鸟、昆虫、布料、头发、旗帜、树和风、轮子和机械、水面。重量、接触、弧线、拖拽和跟随。

| 你现在的程度 | 打开 |
| --- | --- |
| 还没画过像素，或说不清簇、分辨率、剪影 | [初级](references/beginner.md) |
| 能画出可读的静态精灵，要做色阶、描边、简单待机、四帧走、第一种非正面机位 | [中级](references/intermediate.md) |

| 技法已经干净，目标是让作品被记住 | [大师](references/master.md) |

只打开当前任务用得到的那几条。目录页不是课文。

## 默认流程

1. **简报。** 用一句话写下：画什么、给谁看、要传达的动作或地点。例子：画一座宫殿的游客视点，再画同一座宫殿的航拍。
2. **约束。** 先写死画布尺寸、色数上限、唯一机位、有没有动画。像素画用整数倍放大，关掉工具自带的模糊和自动抗锯齿。
3. **剪影。** 用一块局部色把外轮廓画到能认出来。肢体先用分开的色块，不要先画扣子和花纹。
4. **局部色。** 每种材料一块中间色。色要少，每块色要能单独被认出来。
5. **明暗。** 先定一个主光。圆的东西有明暗交界，方的面整面一色。阴影跟着形体，不跟着描边往里一圈圈涂。
6. **动画（如果要动）。** 先做关键姿势，再补中间帧。布、头发、尾巴、旗是跟随，晚于带动它们的身体。
7. **自检。** 按下面的质量门看 1 倍和放大后的两档。过不了就改，不要换一套更花的技法掩盖。

## 柱 1：走路

侧面是教走路的视图。步幅、膝盖和前后脚的遮挡在侧面才看得清。

完整的人走用四个关键姿势，然后左右镜像成一个循环：

1. **Contact**：前脚跟着地，手脚打开，身体偏低。
2. **Down**：体重压上这只脚，头和躯干落到最低。
3. **Pass**：两腿在身体中线交叠。后腿被前腿挡住。身体最高。
4. **Up**：游动的那条腿向前送出，脚还离地。抬起的高度要小。

接着换另一只脚做 Contact，循环接上。

必须同时满足：

- 骨长在每一帧里保持一致。差一个像素，小图上就会一长一短。
- 所有着地的脚落在同一条地面线上。
- 着地的那只脚在画面里向后滑。身体留在原地，这样看起来才是在往前推。
- Pass 是遮挡。游动的脚藏在支撑腿后面或只露出一窄条，两只鞋不要左右并排。
- 抬脚少。夸张的高抬腿会变成踏步或跑步。
- 手臂和异侧的腿一起摆。

正面和四分之三（含常见的俯视四分之三）要把步幅收小。这种角度看不清完整的前后交叉。步子一大，就会腿长不一、两鞋粘在一起，或者一瘸一拐。向上走时，躯干的上下起伏比侧面更小。

方块、体素那类身体用直腿绕髋部摆，像钟摆。不要给这种身体硬装写实膝盖。在四分之三的正面身体上假装有真实膝关节，通常比直腿更难看。

帧数：先做能读懂的 4 个关键姿势。6 帧往往够游戏用。8 帧更顺，但中间帧多了会把力气抽走。12 帧是流畅版本，低分辨率可以把左右各收成 3 帧。细节和衣服等姿势对了再加。衣服的褶皱要在每一帧里从同一处受力点出发。

做走路之前打开 [中级 · 走路](references/intermediate.md)。要交专业循环时再打开 [高级 · 走路](references/advanced.md)，并当场阅读 Pedro Medeiros 的 *Walk Cycle* 和 SLYNYRD 的 *Pixelblog 50*。Slynyrd 把第四个关键姿势写成 swing point，也就是这里的 Up。

## 柱 2：视角

一张图只许一种投影。屋顶的斜线、墙的缩短、地砖的格子，全画面用同一套台阶。

先选机位，再画：

- **正侧面、正前面、正背面。** 垂直于物体的一个面。平行线仍然平行，物体走到哪里都一样大。适合第一只精灵和侧面走路。
- **俯视 / 鸟瞰。** 正上方，主要看见顶面。脚在腿的远处，腿在躯干的远处。
- **四分之三俯视。** 斜上方，同时看见顶和正面。墙是直的，顶面有统一的缩短。RPG 常用这一套。
- **四分之三侧面。** 平视一个墙角，两面墙都看得见。
- **等距。** 斜上方再转约 45°，同时看见顶和两面墙。像素里用干净的 2:1 台阶线（约 26.6°）。真·30° 等距在像素网格上会发虚。
- **游客视点。** 人站在对象前面，视平线大约在眼高或一层门的高度。用正立面时，垂直线保持垂直，地面的平行线保持平行。这是立面，不是镜头照片。
- **航拍。** 正顶，或很高的四分之三 / 等距。屋顶和庭院是主体，墙变得很短。近处的柱子不要突然改成游客立面的比例。
- **虫视（仰视）。** 相机在对象下方。垂直线要向上收。像素网格很难把这种汇聚画干净。没有打开一份讲消失点的课文之前，宫殿和角色都用立面、四分之三或等距，不要现编仰视台阶。

同一座宫殿要交两张图时：先锁尺寸和色板。游客图先定地平线和门的高度，人若出现，身高用门来量。航拍图另起一张画布，用俯视或等距重搭体积，只复用色和材质，不把立面的门宽直接贴到屋顶平面上。

把侧面的大步幅贴到正面或四分之三身体上，腿会断开。侧面的步子留在侧面；正面和俯视用小步，并让脚落在身体的深度顺序里。

## 柱 3：运动轨迹

先问这具身体靠什么接触世界，再画帧。人的 Contact → Down → Pass → Up 不能套到所有物种上。

- **双足。** 用柱 1。侧面教完整步幅。
- **四足。** 当成两套双足，时间错开。后腿比对角的前腿晚一步。前后脚移动的距离要一样，身体才不会像手风琴。奔跑时左右腿更接近并排弹跳，步序和走路不同。先会双足再做四足。
- **鸟和翅膀。** 翅膀是手臂。先标关节，再做扇动的两个极端。向上快，向下慢，因为向下在对抗重力。身体的上下起伏最后再加。快翅（蜂、蝇）用很少的帧，或用重影表示模糊。悬停靠很小的位移，甚至靠亚像素错觉，不靠大跳。
- **昆虫。** 六条腿，三脚架交替：一侧的前、后腿和另一侧的中腿着地，另外三条向前。然后对调。蚂蚁这类身体随时有三只脚撑地。
- **蛇。** 这里没有收录到同样清楚、可公开阅读的蛇类像素课文。不要给人的腿安在蛇身上。任务如果必须是蛇，只交一条能循环的剪影，并写明缺少课文，不要编一套精细帧。
- **布、头发、旗帜、尾巴。** 受力点先动，自由端晚一拍，波越往末端越大。褶皱从被压紧或被拽住的点辐射。布料多是软阴影，少高光。暗部少画褶皱。
- **树和草。** 风本身看不见。把叶子分成几层，每层差一帧地做很小的位移，一层一个来回往往就够。叶子用重复的簇，不要撒孤儿像素。
- **金属、轮子、机械。** 金属又硬又亮。高光冷、面积小，暗部更饱和。零件各自旋转或滑动，不要把车壳拉开。履带、轮辐用很少的帧循环；车身可以轻点头，不要给整辆车加上惯性延迟。水平飞行器表达上下运动时，滚转通常比抬头更干净，因为大角度旋转会把簇拧碎。
- **船和水面。** 水面用循环的波形。浪峰比浪谷更陡。船壳保持刚性，随波上下和轻微俯仰；水花和旗是跟随。没有单独的船体课文时，打开水面课和金属课，不要发明一套泡沫帧。

## 质量门

交稿前逐条看画面：

- 缩到 1 倍仍能认出是谁、朝哪、在做什么。
- 放大后像素是完整的方块，没有自动模糊。
- 簇是故意的。斜线和曲线的台阶长度有规律。没有散落的单像素噪声。
- 色数少，相邻色分得开。主光方向全图一致。
- 描边如果存在，粗细一致；该断开的接触处（脚底、握住的物体）是断开的。
- 全图只有一种投影。
- 走路循环的第一帧和最后一帧能接上。地面是一条线。Pass 帧里能指出哪只脚在前。
- 正面或四分之三的步幅明显小于侧面教学图。
- 物种的着地方式和关节对得上它的身体。跟随物晚于主动作，并在循环里回到起点。
- 每一帧的骨长、簇密度和细节量和别的帧同一水平。
