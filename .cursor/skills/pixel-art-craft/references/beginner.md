# 初级

假定你从未画过像素画。这一级只建立：像素是什么、画布和簇、有限的颜色、线和形、简单明暗、第一只可读的精灵。走路的完整步序、等距网格和其他物种的运动都在后面的等级。先把这一级做完。

三条柱在这一级的任务：

- **走路。** 先不要做循环。把侧面剪影和分开的色块做干净。第一套待机和短跑在中级 *Pixelblog 8*；完整的 Contact → Down → Pass → Up 在高级。
- **视角。** 只画一个正侧面或正前面。远的先画，近的盖住远的。换机位之前打开中级的投影课。
- **运动轨迹。** 先体会“每一帧都是一张新的、故意摆好的图”。不要把走路、翅膀和布料混在第一张图里。

需要哪一课，就在这一轮打开它的 URL。

## 基本功

### The Pixel Art Tutorial

- 作者：cure
- 链接：https://pixeljoint.com/forum/forum_posts.asp?TID=11299
- 主题：像素画的定义、线、抗锯齿、抖动、簇、常见错误、色板
- 为什么要看：这是公开论坛上最完整的入门总纲，专门区分“像素构成的图”和“在像素这一级做决定的图”。
- 打开后抓住：每个像素都要有理由。自动模糊、涂抹和过多接近的颜色会让控制权离开你。斜线的台阶要有规律。抖动是纹理或过渡，散成噪声就失败了。枕头式的一圈圈明暗、锯齿和乱抖动都在这篇的反面例子里。

### 1 - An Absolute Beginner’s Guide

- 作者：Pedro Medeiros（saint11）
- 链接：https://saint11.art/pixel_art_articles/article1/
- 主题：新建文件、画布、色数上限
- 为什么要看：它从“还没打开软件”写起，并坚持像素画仍然是绘画，解剖、光和透视以后都要补，但第一张图先把限制设死。
- 打开后抓住：先定很小的画布和很少的颜色，再下笔。工具会变，色数和尺寸的纪律不会变。

### 2 - Cluster Sketching and Painting

- 作者：Pedro Medeiros（saint11）
- 链接：https://saint11.art/pixel_art_articles/article2/
- 主题：簇、锯齿、由远到近
- 为什么要看：簇是同色且相连的一块像素，相当于这一行当的笔触。这篇把“先大块、再修边”写成可以跟着做的过程。
- 打开后抓住：先用大色块摆气氛，不要先抠细节。从天空和远山画到近处的剪影。斜边的台阶长度要顺着弯势变长或变短，中间突然变短就是锯齿。尽量少留单像素的孤儿点。

### Pixelblog - 5 - Back to Basics

- 作者：Raymond Schlitter（SLYNYRD）
- 链接：https://www.slynyrd.com/blog/2018/5/16/pixelblog-5-back-to-basics
- 主题：什么是像素画、簇、画布、整数倍缩放
- 为什么要看：用同一位作者的树和一张“不是像素画”的涂抹，把定义讲清楚，并给出新手能执行的尺寸和缩放规则。
- 打开后抓住：像素画是故意控制每一个像素。干净的重复簇偏利落，多变的有机簇偏自然。放大只用整数倍，并关掉缩放时的抗锯齿。不知道画多大时，先用远小于屏幕的画布，例如一百像素上下，再按需要加大。

### Pixel Art: Where to Start

- 作者：Lospec
- 链接：https://lospec.com/articles/pixel-art-where-to-start/
- 主题：学习路径
- 为什么要看：它是目录站自己写的起步说明，用来决定下一篇该打开哪篇入门文，而不是把整个教程库读完。
- 打开后抓住：先读一两篇总纲，把术语看熟，再动手。文中提到的付费书不要当成这一级的必读。

## 明暗与极限色

### 4 - Basic Shading

- 作者：Pedro Medeiros（saint11）
- 链接：https://saint11.art/pixel_art_articles/article4/
- 主题：简单明暗
- 为什么要看：用很少的色和很小的画布，把体积阴影、投影、高光和交界线的差别摆出来。
- 打开后抓住：先铺固有色和大块明暗，再加投影和细节。圆的物体有过渡，平的面往往整面一色。像素画里用干脆的交界，避免用很多接近的色做腻的渐变。小图里装不下所有光学名词，装不下的就删。

### 1-Bit

- 作者：Pedro Medeiros（saint11）
- 链接：https://github.com/saint11/Saint11Tutorials/blob/master/1-bit.gif
- 主题：两色、剪影、抖动
- 为什么要看：只剩两种颜色时，形状和取舍会暴露出来。这是有限色板的极端练习，不是特效课。
- 打开后看图，抓住：用线交代大形，用少数实心阴影块交代体积。抖动只用来暗示软阴影，花纹一多就脏。单像素在线条旁边特别显眼。认不出对象就删掉重来，留下最能辨认的那一个特征。
